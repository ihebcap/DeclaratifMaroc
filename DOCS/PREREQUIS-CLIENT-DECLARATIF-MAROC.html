Déclaratif Maroc — Prérequis techniques d'installation

Document à destination du service informatique du client · à valider avant l'installation

Ce document liste les prérequis techniques nécessaires à l'installation de l'application Déclaratif Maroc (déclaration TVA / Délai de Paiement Maroc) sur le poste ou serveur désigné, ainsi que la configuration réseau à prévoir pour un accès depuis les postes du réseau local.

1. Poste / serveur d'installation

ÉlémentPrérequis
Système d'exploitationWindows (poste ou serveur), avec droits administrateur pour l'installation (mise en place d'un service Windows)
.NET FrameworkVersion 4.8 — nécessaire uniquement pour le composant qui dialogue avec les objets métier Sage. Si absent, le programme d'installation propose de l'installer automatiquement (un redémarrage de Windows peut être nécessaire)
.NET 8 / ASP.NET CoreAucune installation requise — le serveur applicatif est livré « autonome » (runtime embarqué dans l'exécutable), rien à installer séparément pour cette partie
Sage 100Une version compatible doit être installée sur ce même poste : v7, v9, v10/v11 ou v12 (la version v8 n'est pas prise en charge)
Espace disqueQuelques centaines de Mo pour l'application (hors bases de données)
Cas particulier — client sans objets métier Sage Si le client ne gère pas ses factures via Sage (saisie 100 % manuelle dans l'application), les objets métier Sage ne sont pas sollicités pour ces pièces. Un accès SQL à la base Sage reste cependant nécessaire pour la lecture des taux de TVA (table de référence des taxes).

Téléchargement — .NET Framework 4.8

Le programme d'installation propose d'installer automatiquement le .NET Framework 4.8 s'il est absent. En cas de besoin d'une installation manuelle préalable (poste sans accès Internet au moment de l'installation, par exemple), le lien officiel Microsoft est :

ComposantLien de téléchargement
.NET Framework 4.8 — Runtime (à installer sur le poste/serveur cible) dotnet.microsoft.com/download/dotnet-framework/net48
Choisir « Runtime » (pas « Developer Pack », réservé aux développeurs).
.NET 8 / ASP.NET Core Runtime (facultatif — déjà inclus dans l'application livrée, uniquement si le client préfère l'installer lui-même séparément) dotnet.microsoft.com/download/dotnet/8.0
Choisir « ASP.NET Core Runtime », Windows, x64.

2. Accès base de données

  • Un serveur SQL Server accessible depuis le poste d'installation, hébergeant la base de données GRF de la société.
  • Un compte SQL (ou Windows) disposant des droits de lecture/écriture sur cette base.
  • Le même serveur héberge généralement aussi la base Sage associée (lue automatiquement par société, aucune saisie séparée nécessaire).

3. Réseau — port à ouvrir pour l'accès local

L'application fonctionne comme un petit serveur web installé sur un poste ou serveur du réseau : les utilisateurs y accèdent depuis leur navigateur, à l'adresse http://<adresse-ip-du-serveur>:<port>.

Le port d'écoute est choisi lors de l'installation (une valeur par défaut est proposée, modifiable si elle est déjà utilisée par une autre application sur ce poste).

Action requise côté réseau/pare-feu Le pare-feu Windows du poste/serveur d'installation doit autoriser les connexions entrantes sur ce port TCP, afin que les autres postes du réseau local puissent y accéder. Sans cette ouverture, seul le poste d'installation lui-même pourra utiliser l'application (via localhost).

Concrètement, à faire une fois le port choisi et l'installation terminée :

  • Créer une règle de pare-feu entrante (TCP) autorisant le port choisi à l'installation.
  • Vérifier depuis un autre poste du réseau que http://<adresse-ip-du-serveur>:<port> répond bien.
  • Si un pare-feu ou antivirus tiers est également en place (au-delà du pare-feu Windows), y ajouter la même autorisation.

4. Licence

L'application nécessite une licence active, vérifiée au démarrage du service. Les informations de connexion au serveur de licence sont renseignées lors de l'installation (valeurs par défaut fournies, modifiables si nécessaire).

5. Résumé — ce qu'il faut avoir prêt avant l'installation

  • Accès administrateur au poste/serveur cible
  • Sage 100 installé (version v7/v9/v10-v11/v12)
  • Adresse et identifiants du serveur SQL Server hébergeant la base GRF
  • Un port TCP disponible sur ce poste (par défaut proposé à l'installation), à ouvrir dans le pare-feu une fois choisi

Document générique — les valeurs spécifiques (adresse serveur, port réellement configuré, identifiants) sont à compléter au moment de l'installation avec l'équipe technique.
